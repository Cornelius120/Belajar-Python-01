Selamat datang di repositori **Belajar Python 01**! 🎓

Repositori ini berisi kumpulan latihan dan proyek Python yang disusun berdasarkan minggu belajar (**Minggu 1–7**), mengikuti alur pembelajaran dari dasar hingga tingkat **intermediate/advanced**. Cocok untuk pemula yang ingin belajar Python dengan cara **terstruktur, praktis, dan menyenangkan**.

---

## 📚 Struktur Folder
```
Belajar Python/
├── Minggu 1 → Pengenalan Dasar Python (Hello World, Variabel, Tipe Data)
├── Minggu 2 → Percabangan, Perulangan, dan Input/Output
├── Minggu 3 → Fungsi, List, Tuple, Dictionary
├── Minggu 4 → File Handling, Error Handling, OOP Dasar
├── Minggu 5 → Inheritance, Modul, DateTime, Random, Mini Project
└── Minggu 6 & 7 → Proyek Intermediate dan Modul Eksternal (JSON, CSV, API)
```

> 🗂️ Setiap folder berisi file Python dengan komentar detail di dalam kode agar mudah dipahami.

---

## 🚀 Cara Menjalankan Kode
1. Pastikan kamu sudah menginstal **Python 3.8+** di komputer kamu.
2. Clone repositori ini:
   ```bash
   git clone https://github.com/Cornelius120/Belajar-Python-01.git
   ```
3. Masuk ke folder yang ingin kamu jalankan, misalnya:
   ```bash
   cd "Belajar Python/Minggu 7"
   ```
4. Jalankan file Python:
   ```bash
   python minggu7.py
   ```

> 💡 Tips: Gunakan **VS Code Terminal** agar pengalaman belajar lebih nyaman.
